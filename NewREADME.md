##  Project Overview
This project is a WPF-based Cybersecurity Chatbot built in C#.  
It combines Parts 1, 2, and 3 of the POE assignment into a single integrated application.  
Features include:
- Interactive chatbot with ASCII art greeting
- Sentiment detection and keyword responder
- Personalized memory (stores user name)
- Task Assistant with JSON persistence (add, complete, delete, reminders)
- Cybersecurity Quiz with scoring, feedback, and hints
- Activity Log with timestamps, numbered entries, and “Show More”
- NLP intent detection for varied phrasing
- GUI integration with tabs for Chat, Task Assistant, and Quiz
